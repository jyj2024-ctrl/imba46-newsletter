이 폴더에 행사 사진을 넣어주세요.

권장 사항
- 가로형 (4:3 또는 16:9) 비율 권장
- 파일명 예시: 2025-08-orientation.jpg, 2025-10-autumn-trip.jpg
- 용량: 1~2MB 이내, 가로 1600px 이내 권장 (모바일 로딩 속도)

연결 방법
1) 이 폴더에 사진을 넣고
2) data/events-past.js 에서 해당 행사의 "image" 값을
   "images/events/파일명.jpg" 형태로 적어주면 자동 표시됩니다.

이미지가 없으면 자동으로 placeholder 박스("사진 들어갈 자리")가 표시됩니다.
